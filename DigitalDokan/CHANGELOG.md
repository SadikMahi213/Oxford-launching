# Changelog

## 1.0.0 (2026-09-09) — Release 1, first commercial release
Offline POS with atomic sales, product catalog + barcodes + CSV import, inventory
ledger with batch/expiry FEFO, purchases + supplier payable, customer due +
credit limits + loyalty points, returns/cancellations as reversals, shifts with
cash reconciliation, expenses, sales/stock/profit/near-expiry reports + CSV
export, thermal receipts + cash drawer trigger, roles/permissions + audit logs,
backup/verify/restore with retention, offline licensing (trial + grace), en/bn
localization, VAT configurable (inclusive/exclusive), installer + manuals.
